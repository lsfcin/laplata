# laplata
> Onde o dinheiro vaza: pipeline de dados abertos + visualizações dos fluxos financeiros extrativos do Brasil.

## What it does

- Ingere dados abertos: BCB (estatísticas Pix, cartões, estudo bets), IBGE/POF (consumo das famílias), fontes municipais
- Quantifica "ralos": fluxos que saem da economia local (taxas de cartão, bets, marketplaces, aluguéis)
- Gera visualizações com tese ("teu bairro manda R$ X/mês pra fora") e relatórios narrados por LLM
- Serve API interna pros outros núcleos do programa instituto
